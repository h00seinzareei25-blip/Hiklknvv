# نظم‌یار — نسخه ۰٫۱

برنامه دسکتاپ ویندوز برای اسکن و دسته‌بندی پیشنهادی فایل‌ها.

## این نسخه چه دارد؟
- ظاهر گرافیکی فارسی و راست‌به‌چپ
- انتخاب پوشه و اسکن فایل‌ها
- تشخیص آفلاین از روی پسوند و اسم (فتوشاپ، اتوکد، فاکتور و…)
- صفحه پیش‌نمایش دسته‌بندی
- صفحه تنظیمات کلیدهای Gemini و OpenRouter (ذخیره محلی — هنوز به API وصل نیست)

## اجرا روی ویندوز
1. فایل `Nazmyar-win32-x64.zip` را از پوشه `dist` دانلود و از حالت فشرده خارج کنید
2. `Nazmyar.exe` را اجرا کنید

> جابه‌جایی فایل‌ها، Undo و اتصال واقعی AI در مرحله‌های بعد اضافه می‌شود.

## توسعه
```bash
cd nazmyar
npm install
npm start
```

ساخت خروجی ویندوز:
```bash
npm run pack:win
```
