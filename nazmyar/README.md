# نظم‌یار — نسخه ۰٫۲

برنامه دسکتاپ ویندوز برای اسکن، دسته‌بندی و پیشنهاد نام فایل با کمک هوش مصنوعی.

## این نسخه چه دارد؟
- ظاهر گرافیکی فارسی و راست‌به‌چپ
- اسکن آفلاین از روی پسوند و اسم فایل
- تحلیل با **Google Gemini** یا **OpenRouter**:
  - پیشنهاد دسته از روی نام فایل
  - پیشنهاد نام بهتر برای فایل
- اعمال تغییر نام تکی یا گروهی (با تأیید)
- ذخیره محلی کلیدهای API

## اجرا روی ویندوز
از ریلیز GitHub فایل zip را دانلود، Extract و `Nazmyar.exe` را اجرا کنید.

## توسعه
```bash
cd nazmyar
npm install
npm start
```

ساخت خروجی ویندوز (از لینوکس، بدون Wine):
```bash
npm run build:win
```
