# آب‌یار

اپلیکیشن بومی اندروید برای پیگیری مصرف آب، محاسبه هدف روزانه بر اساس وزن، یادآوری هوشمند و ویجت صفحه اصلی.

## امکانات نسخه ۱.۱

- رابط کاملاً فارسی و راست‌به‌چپ + حالت تیره
- محاسبه هدف با وزن، سطح فعالیت و هوای گرم (یا هدف دستی)
- ظرف‌های سریع قابل ویرایش + ثبت چای/قهوه/آبمیوه/شیر با ضریب آب‌رسانی
- تاریخچه ساعتی امروز و حذف آخرین ثبت
- Streak روزهای پیاپی + نمودار ۷ روزه + تقویم شمسی ماهانه
- یادآوری هوشمند: پیشنهاد مقدار پویا، رد نوبت پس از نوشیدن اخیر، snooze ۱۵ دقیقه‌ای، پیام‌های متنوع، جمع‌بندی پایان روز
- بازیابی خودکار زنجیره آلارم و راهنمای بهینه‌سازی باتری
- ویجت بزرگ و ویجت دایره‌ای ۱×۱
- پشتیبان‌گیری/بازیابی JSON و خروجی CSV برای اپ‌های سلامت / Health Connect
- ذخیره محلی اطلاعات بدون نیاز به اینترنت

> فرمول آب یک تخمین عمومی برای بزرگسالان سالم است و جای توصیه پزشکی را نمی‌گیرد.

## ساخت APK

پیش‌نیازها: JDK 17 یا جدیدتر و Android SDK 35.

```bash
./gradlew test
./gradlew assembleDebug
```

فایل خروجی در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

یک نسخه آماده نصب نیز با نام `abyar-v1.1.0.apk` در ریشه همین مخزن قرار دارد.

برای نسخه انتشار باید کلید امضای اختصاصی در تنظیمات Gradle اضافه شود؛ نسخه debug برای نصب و آزمایش قابل استفاده است.
