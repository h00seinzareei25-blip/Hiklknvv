# آب‌یار

اپلیکیشن بومی اندروید برای پیگیری مصرف آب، محاسبه هدف روزانه بر اساس وزن، یادآوری هوشمند و ویجت صفحه اصلی.

## امکانات

- رابط کاملاً فارسی و راست‌به‌چپ
- محاسبه هدف روزانه با فرمول عمومی `وزن × ۳۵ میلی‌لیتر`
- ثبت سریع ۲۰۰، ۲۵۰، ۵۰۰ میلی‌لیتر یا مقدار دلخواه
- نمایش پیشرفت، مقدار باقی‌مانده و نمودار هفت روزه
- حذف آخرین ثبت
- یادآوری قابل تنظیم از ۳۰ دقیقه تا ۴ ساعت و بازه زمانی دلخواه
- توقف اعلان‌های همان روز پس از تکمیل هدف
- بازیابی یادآورها بعد از روشن‌شدن دستگاه، تغییر ساعت یا به‌روزرسانی برنامه
- اکشن «نوشیدم» در اعلان و ویجت تعاملی صفحه اصلی
- ذخیره محلی اطلاعات بدون نیاز به اینترنت یا ساخت حساب

> فرمول آب یک تخمین عمومی برای بزرگسالان سالم است و جای توصیه پزشکی را نمی‌گیرد.

## ساخت APK

پیش‌نیازها: JDK 17 یا جدیدتر و Android SDK 35.

```bash
./gradlew test
./gradlew assembleDebug
```

فایل خروجی در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

یک نسخه آماده نصب نیز با نام `abyar-v1.0.0.apk` در ریشه همین مخزن قرار دارد.

برای نسخه انتشار باید کلید امضای اختصاصی در تنظیمات Gradle اضافه شود؛ نسخه debug برای نصب و آزمایش قابل استفاده است.
