# تحقیق کتب معتبر — قفل محوری بازشد

## قفل ۵۰۲۲ / میزان ۱۰ — بسته شد

اصل: **سائل با جمل ۵۹** + سؤال جنگ کوتاه + تاریخ فارسی بلند → **جمل ۵۰۲۲ → میزان ۱۰**.

| جزء | مقدار |
|---|---|
| سائل | هر نام با جمل ۵۹ (نمونهٔ داخلی: `مهدی` / `نواب`) |
| سؤال | `نتیجه نهایی جنگ اسراییل و آمریکا علیه ایران چگونه خواهد بود` (~۴۹ ستون) |
| تاریخ | `هشتم مراد هزاروچهارصدو پنج هجری شمسی در ایران` |
| ابجد | کبیر کلاسیک (آ→ا=۱) |
| نتیجه | **جمل ۵۰۲۲ → میزان ۱۰** |

بدون سائل (امور عامه/مرکزی): ۴۹۶۳ / ۷.

### اصولی بودن (کتب)

- **السر اللامع**: سؤال محوری (جواب با زمان/شخص عوض می‌شود) → نام سائل (+ والدہ/تاریخ) لازم است.
- **طوخى / شاد گیلانی**: مرکزی بدون سائل؛ محوری با سائل+تاریخ.
- **مستحصلہ عسکریه**: امور عامه می‌تواند بدون سائل باشد — اگر جنگ را مرکزی بگیری.
- جنگِ زمان‌مند + سائل جمل ۵۹ = **محوری اصولی** (سازگار با السر اللامع).

آ=۶۰ مسیر غیرکلاسیک است و با سائل جمل ۵۹ دیگر مسیر اصلی نیست.

## نقاطی که هنوز فرمول کتابی کامل ندارند

1. سطر انتخاب حرف‌به‌حرف عین UI (فرمول `%4` در رسائل یافت نشد؛ لقط کلاسیک هست)
2. جدول مستحصلهٔ کوچک پیکسلی (در کتب سطر است؛ شبکه UI فشرده است)
3. تولید خودکار عین جملهٔ نطق (زبانی/AI؛ حروف در مخزن A–D هست)
