# تحقیق کتب معتبر — قفل‌ها

## قفل محوری جمل — بسته شد

اصل: **سائل با جمل ۵۹** + سؤال جنگ کوتاه + تاریخ فارسی بلند → **جمل ۵۰۲۲ → میزان ۱۰**.

| جزء | مقدار |
|---|---|
| سائل | هر نام با جمل ۵۹ (نمونهٔ آزمون: `نواب`) |
| سؤال | `نتیجه نهایی جنگ اسراییل و آمریکا علیه ایران چگونه خواهد بود` (~۴۹ ستون) |
| تاریخ | `هشتم مراد هزاروچهارصدو پنج هجری شمسی در ایران` |
| ابجد | کبیر کلاسیک (آ→ا=۱) |
| نتیجه | **جمل ۵۰۲۲ → میزان ۱۰** |

بدون سائل (امور عامه/مرکزی): ۴۹۶۳ / ۷.

### اصولی بودن (کتب)

- **السر اللامع**: سؤال محوری → نام سائل (+ والدہ/تاریخ) لازم است.
- **طوخى / شاد گیلانی**: مرکزی بدون سائل؛ محوری با سائل+تاریخ.
- **مستحصلہ عسکریه**: امور عامه می‌تواند بدون سائل باشد.

## قفل سطر انتخاب / مستحضره — بسته شد (این دور)

### آنچه در رسائل یافت شد

1. **جدول چهار دستهٔ حروف** (المقدمة الجفرية · المعهد العربي لعلم الجفر):

| دسته | حروف |
|---|---|
| مساوات | ا ج ه ز ط ک م |
| ترفع | ب د و ح ی ل ن |
| تنزل | س ف ق ش ث ذ ظ |
| ترقی | ع ص ر ت خ ض غ |

هر حرف ابجد دقیقاً در یک دسته است (۷×۴=۲۸).

2. **جفر پنج‌سطری ترفع/ترقی/تنزل/مساوات** (منسوب در رسائل فارسی/اردو؛ شاد گیلانی / بدوح یلن): حروف را بر همین چهار عمل جدا می‌کنند و با میزان می‌سنجند.

3. **میزان = دندانهٔ کلید** (آموزش مستحصله · منابع فارسی جفر): بدون میزان حروف ناطق نمی‌شوند. لقط هر Nاُم حرف (N=میزان) هم‌خانوادهٔ تخلیص لقط کلاسیک است.

4. **مستحضره**: سطری که حروف را برای استخراج مستحصله آماده می‌کند (مستحصله در علم جفر).

### آنچه یافت نشد

- فرمول نرم‌افزاری `((ستون × میزان) mod 4)` در رسائل نام‌دار **منقول نیست** (تقریب UIهای دیجیتالی بود).
- جدول کامل «اعداد مقرره» هر دسته در بدوح یلن هنوز به‌صورت عمومی و قابل‌ممیزی در دسترس این تحقیق نبود؛ فعلاً میزان سراسری برای لقط کافی است.

### قاعدهٔ قفل‌شده در برنامه

برای هر ستونِ سؤال:

1. دستهٔ حرف اساس را از جدول بالا بگیر  
2. حرف را از ردیفِ همان عمل بردار  
   - مدل `tttm`: مساوات=A، ترفع=C، تنزل=D، ترقی=B  
   - مدل ربع‌دایره: همان اعمال کلاسیک از اساس ساخته می‌شود  
3. میزان را روی سطر حاصل **لقط** کن (گام = میزان)

حالت سازگاری: `options.selectMode = 'mod4'` همان فرمول قدیمی UI را برمی‌گرداند.
