# تحقیق کتب معتبر — قفل‌ها

## قفل محوری جمل — بسته شد

اصل: **سائل با جمل ۵۹** + سؤال جنگ کوتاه + تاریخ فارسی بلند → **جمل ۵۰۲۲ → میزان ۱۰**.

آ=۶۰ غیرکلاسیک است (آ→ا=۱).

## قفل سطر انتخاب / مستحضره — بسته شد

جدول چهار دسته (المقدمة الجفرية):

| مساوات | ا ج ه ز ط ک م |
| ترفع | ب د و ح ی ل ن |
| تنزل | س ف ق ش ث ذ ظ |
| ترقی | ع ص ر ت خ ض غ |

قاعده: دستهٔ حرف اساس → ردیف همان عمل؛ میزان برای لقط.

### جدول منبع (عیناً از وبلاگ)

| دسته | متن منبع |
|---|---|
| مساوات | الف۲ ج۴ ه۶ ز۸ ط۱۰ ک۳۰ م۵۰ |
| ترفع | ب۱۱۰ د۵۸ و۲۴ ح۱۶ ی۲۴ ل۳۵ ن۱۱۰ |
| تنزل | **ص**۱۲۰ ف۱۶۰ ق۲۰۰ ش۶۰۰ ث۱۰۰۰ ذ۱۴۰۰ ظ**۱۸۰** |
| ترقی | ع۱۴۰ **ص**۱۶۰ ر۴۰۰ ت۸۰۰ خ۱۲۰۰ ض۱۶۰۰ غ۲۰۰۰ |

### اصلاح‌های اعمالی در موتور
- تنزل «ص۱۲۰» → **س=۱۲۰** (ص هم‌زمان در ترقی=۱۶۰ است؛ در چهار دستهٔ کلاسیک حرف تنزل گمشده **س** است).
- ظ «۱۸۰» → **ظ=۱۸۰۰** (الگوی ۲×کبیر: ث۱۰۰۰ ذ۱۴۰۰ ظ۱۸۰۰ غ۲۰۰۰).

### عدد عنصر اربعه (مستحصلہ تکمیل آرزو)
آتش۸ · باد۷ · آب۶ · خاک۵

`حرف‌سنجیده = طرح۲۸( عددمقرره(حرف) + میزان )` روی دایرهٔ وضعی ابجد.

## قفل نطق یک‌خطی — لایهٔ کلاسیک بسته شد

### مسیر A — مشهور بین علما
منبع: [مستحصله در علم جفر](https://jahan22.blogfa.com/post/1758) + مثال همان صفحه:

`مستحصله → نظیرهٔ قمری → مؤخرصدر → خواندن متصل`

مثال تأییدشده: `لظسوغخفقصع → ضمارنیجهدب → بضدمهاجرین` (= بضد مهاجرین).

یادداشت: چون نظیره حرف‌به‌حرف است، `نظیره∘مؤخرصدر = مؤخرصدر∘نظیره`.

### مسیر B — خودناطق تکمیل آرزو
منبع: [مستحصلہ تکمیل آرزو](https://www.roohanialoom.com/archives/8865):

`مستحصله → نظیرهٔ ابجد قطب → مؤخرصدر ×۲ → نظیرهٔ قمری → ملاً بخوان`

دایرهٔ ابجد قطب (وهبی): `س و ا ل ع ظ ی م خ ق ح ز ت ف ص ن ذ غ ر ب ش ک ض ط ه ج د ث`

### آنچه هنوز ادبی است
عین جملهٔ اسکرین (`نادم شوند که … باخت سخت`) ترکیب زبانی روی مخزن A–D است؛ فرمول حرف‌به‌جملهٔ اجباری فارسی در رسائل جدولی یافت نشد. برنامه بذر حرفی + بخش‌بندی متصل + واژه‌پوش می‌دهد؛ جملهٔ ادبی نهایی با AI/زبان روی همان بذر ساخته می‌شود.

### آنچه برنامه حالا می‌دهد
- مسیر A و B هر دو
- بخش‌بندی متصل حروف خوانش
- پیشنهاد واژه‌های کاملاً پوش‌شده از مخزن
- پرامپت AI همان بذرها را می‌گیرد

## افزودهٔ v3 (از تحقیق کتب + ایدهٔ جفر)

- راهنمای صورت‌مسئله در UI (محوری/مرکزی، تاریخ حروفی، صبر در خوانش)
- نمایش **سطر مستحصله** به‌عنوان اصل؛ شبکهٔ فشرده فرعی/جمع‌شونده
- بلوک **خوانش / بذر نطق** در نتیجه (مسیر A/B + پیشنهاد + واژه‌پوش)
- بذر نطق روی مسیر کلاسیک و ۱۵ سطری هم
- تأکید پرامپت: نطق مرتبط با پرسش + سطر اصل است
- **چک‌لیست ناطق کردن** + نمونه‌های کارشده (بضد مهاجرین، سبک اسکرین، اصل خطای نطق)
- پرامپت مولّد همان چک‌لیست و نمونه‌ها را می‌گیرد
- پروفایل **علت/وضعیت جسمی‌رمزی**: بانک آری/خیر غالب نمی‌شود؛ نطق از بذر؛ بدون تشخیص پزشکی
- دکمهٔ **پرامپت بهبود سؤال برای AI** زیر متن سؤال (خروجی: مدعا + سؤال دقیق برای پیست دستی)

## تاریخ حروفی (UI)

تاریخ سؤال باید در فیلد جدا، به فارسی حروفی شبیه اسکرین باشد:

`پانزدهم مرداد هزار و چهارصد و پنج هجری شمسی در ایران`

- وارد جمل/میزان می‌شود؛ ستون جدول فقط از متن سؤال است.
- دکمهٔ «امروز فارسی» همین قالب را می‌سازد (نه `1405/05/15`).
- رقم عددی با تاریخ حروفی هم‌ارز نیست و جواب را عوض می‌کند.
